# InterpretML_2019

1. InterpretML 是一個統一了玻璃盒模型與黑盒模型解釋技術的框架，透過統一的 API 提升機器學習的可解釋性與模型間的比較效率

2. Glassbox vs. Blackbox 
- Glassbox：線性模型：結構簡單，特徵權重直接代表影響力 | 規則表：透過邏輯規則序列進行決策
- Blackbox：LIME：透過局部代理模型解釋單一預測 | SHAP：基於賽局理論分配各特徵對預測的貢獻

- 為什麼把 Glassbox 和 Blackbox 放在一起？
  InterpretML 的設計初衷是為了提供統一的 API，讓使用者能在同一個工作流中無縫切換兩種類型，為了讓開發者能進行模型對比。 
- 試圖解決的社群問題：
  高風險領域的合規性：為了解釋高風險存在的原因，若模型無法解釋就難以被法律或社會接受。
  模型除錯：幫助開發者發現數據中的偏差或錯誤邏輯推導。

- 統一 API 跟 sklearn 的異同？
  相似性：一樣使用 .fit(X, y) 來訓練模型
  差異性：加了專門為解釋設計的接口，如 .explain_global() 和 .explain_local(X, y)

- Ease of comparison 具體怎麼體現？內建視覺化儀表板。
  統一視覺化標準：無論使用哪種演算法，都會轉化成統一的 Explanation 物件 。  
  橫向對比：可以在同一個 UI 介面中切換不同的演算法，直觀地看出不同解釋方法是否達成共識 。  

3. EBM 是一種廣義加性模型，其數學公式為：g(E[y]) = β₀ + Σ fⱼ(xⱼ)
- g(連結函數) ：負責將加性模型的輸出轉換至目標尺度 
- β₀(截距/偏移量)：代表模型在沒有任何特徵輸入時的基準預測
- 多了 Pairwise 代表模型不僅考慮單一特徵 xⱼ 的影響，還自動偵測並加入兩個特徵之間的交互作用，提升了捕捉複雜關係的能力卻仍 能保持圖表可視化 

4. Round-Robin Boosting 演算流程
   1. 特徵循環：模型以循環制遍歷所有特徵
   2. 單一特徵訓練：每一輪僅針對一個特徵 xⱼ 訓練一個微小的梯度增強學習器 
   3. 殘差更新：在學習完單一特徵後更新殘差，再進入下一個特徵  
   4. 低學習率限制：使用極低的學習率，確保特徵處理順序不會影響最終結果，並有效減輕共線性帶來的偏差

- 為什麼要 Round-robin？
  為了防止特徵之間的惡性競爭。如果特徵 A 和 B 高度相關，一般的梯度增強可能會讓 A 拿走所有功勞；但 Round-robin 強制兩者公平輪流貢獻，這能有效減輕共線性的影響，使解釋結果更穩健 。

5. Bagging 怎麼帶來信賴區間？：
   EBM 會訓練多個不同的 Bags。當把所有袋子產生的特徵函數 fⱼ 疊加在一起時，不同袋子之間的預測變異就可以轉化為標準差或信賴區間。在視覺化中，可以看到曲線周圍有一圈陰影，那代表模型對該區間特徵影響力的信心水準。  
- Boosting：負責學習特徵與目標之間的非線性關係。
- Bagging：負責降低模型的方差，提升穩定性，並提供不確定性的評估 。

6. 交互：Automatic Interaction Detection
- 如何篩選？ EBM 在完成單變量學習後，會從候選對中自動尋找能最大程度降低殘差的特徵對，FAST 演算法介入。
- GA²M 的 GA²：EBM 本質上就是 GA²M 的高效實現 。其中的 A² 是指代加性且包含二階交互項的意思
- FAST：在完成單特徵學習後，會使用一種快速排序方法篩選出能最顯著提升模型準確率的特徵對，使得模型在維持可解釋性的同時，具備捕捉非線性特徵關係的能力。

7. EBM 與 pyGAM 的 3 個差異
   1. 學習演算法：EBM 使用現代機器學習的 Boosting 與 Bagging；傳統 GAM 通常依賴 Splines 或 Backfitting。  
   2. 交互項處理：EBM 具備自動化交互項偵測；傳統 GAM 通常需要手動指定特徵對。  
   3. 預測速度：EBM 訓練完成後會轉化為查詢表，預測時僅需加法運算，執行速度極快且內存佔用低 。
