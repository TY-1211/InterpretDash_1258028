# 1. EBM 三個核心概念
在 EBM 的眾多特性中，我認為最影響後續介面設計的三個核心概念分別是 Shape Function、Additive Contribution 與 Uncertainty。首先，Shape Function 是 EBM 最具代表性的解釋方式，每個特徵都會對應一條函數曲線，用來描述不同特徵值對預測結果的影響程度。與傳統黑盒模型相比，使用者可以直接觀察特徵與預測之間的關係，因此後續設計中需要以折線圖、區間圖或互動式曲線視覺化作為主要呈現方式。
第二個核心概念是 Additive Contribution。EBM 的預測結果來自各個特徵貢獻值的加總，每個特徵都會對最終預測產生正向或負向影響。這種結構讓模型具備高度可解釋性，也使得介面設計必須提供貢獻排序、Waterfall Chart 或 Feature Ranking 等元件，協助使用者理解哪些因素對結果影響最大，以及最終預測是如何形成的。
第三個核心概念是 Uncertainty。由於 EBM 使用 bagging 技術訓練多個模型，因此除了平均形狀函數外，還能提供 upper bounds 與 lower bounds 等資訊，反映模型對不同區域的信心程度。若僅顯示平均曲線，容易讓使用者誤以為模型對所有區間都具有相同可信度，因此設計時應考慮加入信賴區間、陰影帶或警示標記等視覺元素。綜合而言，Shape Function 決定了解釋內容的呈現方式，Additive Contribution 決定個別預測的解釋流程，而 Uncertainty 則提供模型可靠性的資訊，三者共同構成後續五個作品設計的重要基礎。

# 2. Gamut 三個設計原則
在 Gamut 提出的多項設計原則中，我認為對五個作品影響最大的原則為 Explainability（C1）、Direct Manipulation（C3）以及 Human-in-the-loop（C5）。首先，Explainability 是整個系統的核心目標。Gamut 強調使用者不只是觀看模型結果，而是要真正理解模型行為與決策依據。因此在所有作品中，都必須提供模型解釋相關元件，例如 Shape Function、Feature Importance、Contribution Ranking 或 Prediction Explanation，讓使用者能從不同角度理解模型運作邏輯，而非僅獲得一個預測數值。
其次，Direct Manipulation 強調使用者可以直接與模型互動並進行修改，而不是透過複雜指令或程式碼完成操作。這項原則在 GAM Changer 中尤其明顯，使用者能直接拖曳曲線、增加控制點或修改函數形狀。因此在後續設計中，若希望支援模型調整與知識注入，就需要設計可編輯的視覺元件，例如曲線編輯器、控制點介面或互動式參數調整工具，讓專家能以直觀方式修正模型。
最後，Human-in-the-loop 強調人類專家在模型建構與修正過程中的重要角色。Gamut 認為最佳模型不一定完全依賴演算法，而是結合專家知識與資料驅動結果共同產生。因此介面設計除了展示結果外，也應支援假設驗證、修改紀錄、效能回饋以及版本管理等功能，使使用者能在觀察、修改、評估與再修改之間形成循環。這三項原則分別對應「理解模型」、「修改模型」以及「持續參與模型優化」，也是後續五個作品設計時最重要的設計依據。

# 3. 與 GAM Changer 的差距
根據 Gamut 與 GAM Changer 的功能比較，可以發現目前規劃的五個作品雖然已涵蓋模型解釋與互動編輯功能，但仍有部分值得補強的地方。首先，我認為最值得加入的是不確定性視覺化。GAM Changer 主要聚焦於 Shape Function 編輯與模型效能變化，較少呈現 EBM 本身提供的 upper bounds 與 lower bounds 資訊。然而在醫療與高風險決策情境中，模型信心往往與預測結果同樣重要，因此加入信賴區間或不確定性提示具有實際價值。
其次，可補充 What-if Analysis 功能。現有設計大多呈現全域解釋與曲線修改結果，但若能讓使用者即時觀察特定個案在修改前後的風險變化，將更符合臨床決策支援需求，也更容易驗證模型修改是否合理。
相對地，有些功能則不需要納入。例如多人即時協作與複雜版本控制雖然出現在部分研究系統中，但對本次課程作品而言實作成本較高，且與主要學習目標關聯有限。此外，大規模多模型比較平台也超出目前專案範圍。因此本次設計將優先強化模型解釋、不確定性呈現與專家互動能力，而不追求完整的企業級模型管理功能，以兼顧實作可行性與設計價值。
